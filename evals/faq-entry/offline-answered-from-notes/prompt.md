Question as it came in: "does it still work if im on a train with no signal?"

Notes from the requirements page: Harbourline Format runs inside desktop Word
and inside Word for the web. The desktop add-in applies house style with no
network connection, because the rules live on the machine. Word for the web
needs a connection, because Word itself does. A document formatted offline
syncs the next time the machine is online.
