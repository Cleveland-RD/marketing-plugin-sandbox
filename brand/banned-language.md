# Banned language - never publish

> SYNTHETIC PILOT DATA for a fictional company.

## Punctuation

- em dash `—`
- semicolon `;` in body copy
- exclamation mark `!`

## Phrases (zero tolerance)

- leverage
- delve
- unlock
- seamless
- frictionless
- robust
- game-changer
- revolutionary
- cutting-edge
- in today's fast-paced world
- at the end of the day
- moving forward
- learn more
- find out more
- delighted to announce

## Patterns

- Three-adjective lists: "fast, simple, reliable"
- Rhetorical question openers: "Ever wondered why...?"
- "Not just X, but Y" framing

## Allowed substitutes (optional)

- Instead of "leverage" use: use, apply, run
- Instead of "seamless" describe what actually happens
